# MyM Codex Skills

Repositorio privado de skills para los proyectos Asistente_Codex de MyM.

Cada skill vive en su propia carpeta dentro de skills/.

## Instalar una skill en Asistente_Codex

Copiar la carpeta de la skill deseada a .agents/skills/ dentro del proyecto. Por ejemplo: skills/xubio-papeles-rivadavia.

Las skills contienen instrucciones y referencias. Cada equipo debe configurar por separado la conexión y las credenciales de Xubio. No subir archivos .env, tokens, contraseñas ni datos de autenticación al repositorio.

## Skills disponibles

- [Papeles de Carpintería Rivadavia en Xubio](skills/xubio-papeles-rivadavia/): presupuestos, comprobante de venta y remito valorizado.

Para sumar una skill, crear una carpeta nueva en skills/<nombre> con su SKILL.md, las referencias necesarias y, si corresponde, metadatos de agente.
